# ZedroBank - Modern Digital Banking Interface

ZedroBank is a secure and user-friendly banking frontend application designed to provide a seamless digital banking experience. This interface focuses on clean UI/UX, allowing users to manage their finances, view transactions, and handle authentication securely.

## 🚀 Key Features

* **Secure Authentication:** Integrated login and registration forms with robust validation.
* **Real-time Dashboard:** A comprehensive view of account balances and recent activities.
* **Transaction Management:** Easy-to-use interface for transferring funds and tracking history.
* **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
* **Security First:** Built with modern web security practices to prevent unauthorized access.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Styling), JavaScript (ES6+)
* **Security:** Integrated with Spring Security (Backend)
* **Tools:** VS Code, Git for version control

## ⚙️ How to Run Locally

1.  Clone the repository:
    ```bash
    git clone [https://github.com/MOHANIOZ/ZedroBank.git](https://github.com/MOHANIOZ/ZedroBank.git)
    ```
2.  Navigate to the project folder:
    ```bash
    cd banking-app
    ```
3.  Open `index.html` using a **Live Server** (VS Code Extension) or any local web server to avoid CORS/File-origin issues.
