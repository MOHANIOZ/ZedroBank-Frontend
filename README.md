# 🏦 ZedroBank - Modern Digital Banking Dashboard

ZedroBank is a sleek, dark-themed premium banking dashboard UI. It features a modern interface for managing accounts, viewing transactions, and performing quick financial actions.

## ✨ Features
- **Modern Dark UI:** High-contrast design with a focus on readability and aesthetics.
- **Interactive Dashboard:** View account balance, recent activities, and quick stats at a glance.
- **Responsive Design:** Optimized for desktops and mobile devices.
- **Smooth Animations:** Includes custom loaders, toast notifications, and modal transitions.
- **Quick Actions:** Easily accessible buttons for Money Transfer, Bill Pay, and Card Management.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure for the web.
- **CSS3:** Custom variables, Flexbox, CSS Grid, and Keyframe animations.
- **Google Fonts:** 'DM Sans' and 'Syne' for a premium typography feel.
